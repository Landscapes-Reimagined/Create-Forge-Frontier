# **Forge Frontier v3.0.0 Server Pack**

# **Important Notice**

> **⚠️ A new world is required for Forge Frontier v3.0.0.**
>
> Due to extensive changes to world generation, progression, recipes, structures, dimensions, and core gameplay systems, **existing worlds from previous versions are not compatible with v3.0.0**. We strongly recommend starting with a fresh world to experience the pack as intended.

> Existing worlds should only be kept for archival purposes and are not supported with this release.
