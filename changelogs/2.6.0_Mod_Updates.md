# **Modpack Mod Updates: Version 2.6.0**

## **Introduction**
This update focuses on improving overall stability, compatibility, and performance while preparing the modpack for future content updates. Version 2.6.0 includes a wide range of mod updates, library improvements, and the removal of outdated or incompatible components to ensure a smoother experience with Create v6.0.8 and beyond.

## **Removed or Deprecated Mods**
The following mods have been removed or deprecated to improve compatibility, reduce redundancy, and eliminate known sources of instability:

- **Item Obliterator**: Removed as its functionality is now fully handled through JEI blacklist configuration.  
- **Petrol Park**: Removed due to incompatibility with Create v6.0.8.  
- **Petrol Parts**: Removed due to incompatibility with Create v6.0.8.  
- **Despawn Tweaks**: Removed due to reliance on embedded Fabric APIs that caused cross-loader compatibility issues.  
- **Distraction Free Recipes**: Removed due to reliance on embedded Fabric APIs that caused cross-loader compatibility issues. 
- **Sodium Dynamic Lights**: Removed due to reliance on embedded Fabric APIs that caused cross-loader compatibility issues. 
- **Sodium Options API**: Removed due to reliance on embedded Fabric APIs that caused cross-loader compatibility issues.  
- **Bad Optimizations**: Removed due to reliance on embedded Fabric APIs that caused cross-loader compatibility issues. 
- **Txnilib**: Removed due to reliance on embedded Fabric APIs that caused cross-loader compatibility issues.  
- **Noisium**: Removed as the project is no longer available on CurseForge.

## **Closing Notes**
These changes ensure Forge Frontier remains stable, performant, and fully compatible with Create v6.0.8, while laying the groundwork for future content expansions and feature updates.
