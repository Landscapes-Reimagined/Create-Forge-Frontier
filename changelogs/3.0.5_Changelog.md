## Mod Removals
- **FTB Backups**: Backups are not functioning properly causing world generation to revert to previous stages, reseting player builds and other structures.

---

## **KubeJS & Script Changes**

### Data Updates
- **kubejs\data\create_easy_structures\loot_tables\chests\epic_chest**: Increased Chromatic Compound weight to be far more common than before making it easier to obtain
- **kubejs\data\create_dd**: Added missing Loot Tables for Infa Blocks and Rubber Sappling, and updated Infa Block conversion recipe to give back Stargaze Singularity instead of Fallen Stargaze Singularity

### Server Script Updates
- **kubejs\server_scripts\Compat\Create - Forge Frontier\Mixing_Recipes**: Created Custom Blaze Powder Recipe using Lava, Cinder Flour, and Gunpowder in a mixer
- **kubejs\server_scripts\Compat\Tags**: Added Missing Item Tags for Crushed End Ores and Resonite
- **kubejs\server_scripts\Compat\Resource Vents\Sequenced_Assembly_Recipes**: Updated Vent Duplication Recipes to be more fair by changing to loop 3 times, and lowering compression size for precision mechanism blocks.
- **kubejs\server_scripts\Mod Adjustments\Create Diesel Generators**: Created Custom Recipes for Molds that won't conflict with other recipes

---

- Memory Settings: Updated outdated recommended Memory Settings config to help first time launch issues
