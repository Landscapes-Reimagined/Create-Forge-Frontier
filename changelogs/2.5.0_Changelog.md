## ✅ Mod Additions
- **[Advanced Loot Info](https://www.curseforge.com/minecraft/mc-mods/advanced-loot-info)**  
  Displays detailed tooltips for loot tables and drop chances, helping players understand item sources more clearly.

- **[Building Gadgets](https://www.curseforge.com/minecraft/mc-mods/building-gadgets)**  
  Offers powerful tools for efficient large-scale building and block placement.

- **[Create: Alex's Caves Compat](https://www.curseforge.com/minecraft/mc-mods/create-alexs-caves-compat)**  
  Adds Create-themed integration and mechanics to content from Alex's Caves.

- **[Create: Better Motors](https://www.curseforge.com/minecraft/mc-mods/create-better-motors)**  
  Adds compact and efficient electric motors to streamline Create power setups.

- **[Create: Ender Transmission](https://www.curseforge.com/minecraft/mc-mods/create-ender-transmission)**  
  Enables wireless power and rotational force transmission across long distances.

- **[Create: Hypertubes](https://www.curseforge.com/minecraft/mc-mods/hypertubes)**  
  Introduces high-speed transportation tubes compatible with Create mechanics.

- **[Create: Metallurgy](https://www.curseforge.com/minecraft/mc-mods/create-metallurgy)**  
  Adds Create-compatible processing chains for various metal ores, enhancing automation and resource refining.

- **[Create: Ornithopter Glider](https://www.curseforge.com/minecraft/mc-mods/create-ornithopter-glider)**  
  Introduces a functional Create-powered glider for mid-air travel and exploration.

- **[Create: Steam 'n' Rails](https://www.curseforge.com/minecraft/mc-mods/create-steam-n-rails)**  
  Expands Create’s railway system with new trains, tracks, decorations, and steam-powered rail features for immersive transportation networks.

- **[Create: Templates & Gears](https://www.curseforge.com/minecraft/mc-mods/create-templates-gears)**  
  Adds new gear crafting systems and blueprint templates for more modular engineering.

- **[Item Obliterator](https://www.curseforge.com/minecraft/mc-mods/item-obliterator)**  
  Adds a configurable, server-friendly item deletion block for lag reduction and automation.

- **[Lithostitched](https://www.curseforge.com/minecraft/mc-mods/lithostitched)**  
  A library mod for Forge and Fabric with new configurability and compatibility enhancements for worldgen.

- **[More MobGriefing Options](https://www.curseforge.com/minecraft/mc-mods/more-mobgriefing-options)**
  More MobGriefing Options adds, that you can change MobGriefing per entity.

- **[Petrol's Parts](https://www.curseforge.com/minecraft/mc-mods/petrols-parts)**  
  A utility mod that expands part crafting and structure tools, often used by other tech mods.

- **[Petrolpark Library](https://www.curseforge.com/minecraft/mc-mods/petrolpark-library)**  
  A required dependency for mods like Petrol’s Parts, providing shared backend support.

- **[Powah! (Rearchitected)](https://www.curseforge.com/minecraft/mc-mods/powah-rearchitected)**  
  Provides a modular and scalable energy generation system, reimagined for modern integration.

- **[ProbeJS](https://www.curseforge.com/minecraft/mc-mods/probejs)**  
  A developer-focused tool that allows real-time inspection and debugging of Minecraft objects, blocks, and entities directly within the game using KubeJS.

- **[Trials Chambers [1.20.1 Backport]](https://www.curseforge.com/minecraft/mc-mods/trials-chambers-backport)**
  This mod adds the content from the Tricky Trials update to Neo/Forge 1.20.1

- **[Utilitarian](https://www.curseforge.com/minecraft/mc-mods/utilitarian)**  
  Adds practical and decorative utility blocks for tech and factory builds.

- **[Apotheotic Additions](https://www.curseforge.com/minecraft/mc-mods/apotheotic-additions)**
  Apotheotic Additions is an addon that seeks to bridge the gap between multiple mods and Apotheosis, adding in a plethora of cross-mod content, with even more to come.

- **[Apotheotic Creation (Create 6.0)](https://modrinth.com/mod/apotheotic-creation-6.0)**
  Port of Apotheotic Creation. Simple addon which allows defining Create attribute filters for Apotheosis rarities and affixes.

- **[Create: Compatible Storage](https://www.curseforge.com/minecraft/mc-mods/create-compatible-storage)**
  Modded chests variants on contraptions are not treated as an inventory and therefore can't pick up items from contraption actors, be opened by hand or accessed by portable storage interfaces. This mod aims to fix this issue by adding the proper block tags, so you can use prettier chests.

- **[Create: Abyss Catalysis](https://www.curseforge.com/minecraft/mc-mods/create-abyss-catalysis)**
  This addon adds Sculk Catalytic Chamber and Mechanical Shrieker, which need to pair up to work.

## 🎨 Resource Pack Additions
- **[Create: Reimagined](https://www.curseforge.com/minecraft/texture-packs/create-reimagined)**  
  A visual overhaul of Create’s textures, offering a cleaner and more polished aesthetic.

- **[Building Gadgets AE2 Style](https://www.curseforge.com/minecraft/texture-packs/building-gadgets-ae2-style)**  
  Retextures Building Gadgets tools to match the Applied Energistics 2 visual style.

- **[Create: Fixed Redstone Links](https://modrinth.com/resourcepack/create-fixed-redstone-links)**  
  Corrects the vanilla Create redstone link model to align better with textures and expectations.

- **[[Moonsu] Better GUI for FarmingForBlockheads](https://www.curseforge.com/minecraft/texture-packs/moonsu-better-gui-for-farmingforblockheads)**
  A fully customized GUI interface to enhance the market!

- **[Create Style Hotbar](https://www.curseforge.com/minecraft/texture-packs/create-style-hotbar)**
  This is a small resource pack focused on customizing the Minecraft Hotbar.

- **[Create Immersive Aircraft : Warship](https://www.curseforge.com/minecraft/texture-packs/create-immersive-aircraft-warship)**
  This resource pack changes the texture (and even model) of the Warship to look more like it belongs in the Create Mod, working for Immersive Aircraft

- **[Create Immersive Aircraft : Bamboo Hopper](https://www.curseforge.com/minecraft/texture-packs/create-immersive-aircraft-bamboo-hopper)**
  Changes the textures of "Bamboo Hopper" of the Immersive Aircraft mod to look more like they belong in the Create Mod

- **[Mandala's GUI Vanilla Crosshair](https://www.curseforge.com/minecraft/texture-packs/mandalas-gui-vanilla-crosshair)**
  Mandala's GUI textures the crosshair differently from vanilla's. This resourcepack is a patch to reintroduce the vanilla crosshair.
