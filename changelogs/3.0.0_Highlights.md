# **Modpack Patch Notes: Version 3.0.0**
**Release Date:** July 12th, 2026  

### *The Final Frontier*

# **⚠️ Important: New Worlds Are Required**

Version **3.0.0** introduces extensive changes to world generation, progression, storage systems, structures, recipes, and overall gameplay. **Existing worlds from previous versions are not compatible with this update and cannot be migrated.**

To experience **The Final Frontier** as intended, **you must create a brand-new world** after updating. Attempting to continue an existing world may result in missing content, broken progression, world generation issues, recipe inconsistencies, missing structures, or other unexpected behavior.

If you wish to preserve an existing save for reference or nostalgia, we strongly recommend creating a backup before updating. However, **backups are for archival purposes only and should not be used to continue progression in Version 3.0.0.**

---

## **Overview**

Version **3.0.0**, *The Final Frontier*, is the largest update in Create - Forge Frontier's history, introducing a complete overhaul of storage progression, expanded planetary exploration, modernized combat, and one of the most extensive Create integration updates the pack has ever received. Nearly every progression system has been refined to provide a more cohesive, automation-focused experience while improving performance, stability, and overall gameplay.

This release also serves as the final major content expansion for Forge Frontier, bringing together months of development into a single update that strengthens the pack's identity while establishing a solid foundation for future maintenance and community-driven improvements.

---

## **Key Highlights**

- **⚠️ Fresh World Required:** Due to extensive changes to world generation, progression, and core gameplay systems, **existing worlds from previous versions are not supported.** A new world is required to experience Version **3.0.0** as intended.
- **Complete Storage Overhaul:** Applied Energistics 2 has been replaced with Tom's Simple Storage and Refined Storage, delivering a more streamlined and Create-focused storage progression.
- **Expanded Space Exploration:** Added new planetary structures, dungeons, bosses, tools, and exploration content through extensive Ad Astra integrations.
- **Modernized Combat System:** Introduced Better Combat, Expanded Combat, Combat Roll, and numerous compatibility addons to create a smoother and more immersive combat experience.
- **Massive Create Expansion:** Added dozens of Create addons, automation mechanics, decorative options, logistics improvements, and new production systems.
- **World Generation Improvements:** Expanded exploration with Create-themed structures, improved biome integration, enhanced End generation, and refined structure placement.
- **Extensive Progression Rework:** Hundreds of custom recipes, automation chains, and progression paths have been redesigned to better align with Create's mechanical gameplay.
- **Performance and Stability Improvements:** Added new optimization mods, updated existing libraries, removed outdated content, and improved compatibility across the pack.
- **Largest Technical Update Yet:** Hundreds of KubeJS scripts, datapacks, assets, textures, and configuration files have been updated to create the most polished version of Forge Frontier to date.
- **Forge Loader Update**: Updated the mod loader from Forge 47.4.0 to Forge 47.4.20, bringing improved compatibility, stability, and support for newer mods and features.
