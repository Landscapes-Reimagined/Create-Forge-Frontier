# **Create - Forge Frontier: Version 3.1.5**
### *The Final Frontier*

### **Introduction**

Version **3.1.5** is a maintenance, performance, and stability update focused on refining the technical foundation of *Create - Forge Frontier* following continued testing of the Version **3.1.x** release cycle.

This update introduces a substantial cleanup of the modpack's optimization stack, replaces Create Power Loader with a more manageable chunk-loading system, introduces new performance and utility mods, and updates numerous existing mods for improved compatibility. Several KubeJS recipes, custom assets, mob spawning configurations, and server performance settings have also been revised as part of the update.

No major progression or world generation changes are introduced in this release, and existing worlds from Version **3.0.0 and later** remain fully compatible.

---

### **Overview**

Version **3.1.5** focuses on simplifying and strengthening the modpack's performance and compatibility stack while removing components that were no longer providing a meaningful benefit.

A number of optimization and utility mods have been removed following testing, either because their functionality was unused, redundant, or provided no measurable improvement within the modpack. New additions such as **C2ME Forge** expand chunk-generation and loading optimizations, while several other additions provide targeted client, server, and compatibility improvements.

**Create Power Loader** has been replaced with **Chunk Loaders**, providing a more manageable chunk-loading system that can automatically disable chunk loading when players are inactive. Custom Mechanical Crafting and Sequenced Assembly recipes have been introduced to integrate the new chunk loaders into the pack's Create-focused progression.

KubeJS has also received several updates, including new incomplete items and assets for Sequenced Assembly recipes and revised Dirty Dust byproducts for Calorite, Ostrum, Stellaris, and Uraniumnite. Configuration changes further refine mob spawning, interface compatibility, and ServerCore distance settings to improve overall server performance.

Together, these changes streamline the technical foundation of *The Final Frontier* while preserving the core gameplay, progression, and world compatibility established throughout Version **3.0.0 and later**.

## Mod Additions
## **Mod Additions**
- **[C2ME Forge](https://www.curseforge.com/minecraft/mc-mods/concurrent-chunk-management-engine-forge)** - A Forge port of the Concurrent Chunk Management Engine that improves chunk generation and loading performance through multithreaded processing.
- **[Chunk Loaders](https://www.curseforge.com/minecraft/mc-mods/chunk-loaders)** - Adds tiered chunk loaders capable of keeping increasingly larger areas loaded while players are away.
- **[FlickerFix](https://www.curseforge.com/minecraft/mc-mods/flickerfix)** - Replaces the flashing effect at the end of Night Vision with a smoother fade-out.
- **[Mob Despawn Timers](https://www.curseforge.com/minecraft/mc-mods/mob-despawn-timers)** - Prevents mobs from naturally despawning until they have existed for a configurable minimum amount of time.
- **[No Chat Reports](https://www.curseforge.com/minecraft/mc-mods/no-chat-reports)** - Removes chat message signatures and disables Minecraft's player chat reporting functionality where possible.
- **[Sodium/Embeddium Dynamic Lights](https://www.curseforge.com/minecraft/mc-mods/dynamiclights-reforged)** - Adds dynamic lighting support for held and dropped light-emitting items with integration for Embeddium's rendering system.
- **[Sodium/Embeddium Options API](https://www.curseforge.com/minecraft/mc-mods/sodium-options-api)** - Provides an API for mods to integrate additional configuration options and categories into the Sodium and Embeddium video settings interface.
