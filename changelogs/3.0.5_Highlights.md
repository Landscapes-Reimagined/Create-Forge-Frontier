# **Modpack Patch Notes: Version 3.0.5**
**Release Date:** August 5th, 2026

### *The Final Frontier*

#### **⚠️ Updating from before v3.0.0?**

If you're updating from **any version prior to v3.0.0**, we strongly recommend reviewing the following before updating:

- **[v3.0.0 Highlights](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.0.0_Highlights.md)**
- **[v3.0.0 Changelog](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.0.0_Changelog.md)**

These documents cover the major progression, world generation, storage, recipe, and gameplay changes introduced in *The Final Frontier*.


Version **3.0.5** is the fifth maintenance update following *The Final Frontier*. This release focuses on bug fixes, compatibility improvements, quest corrections, and updated mods without changing progression or requiring a new world.

---

## **Overview**
Version **3.0.5** builds upon the foundation established in **Version 3.0.0**, improving stability, compatibility, and overall polish while maintaining full world compatibility with existing **3.0.0** saves.

---

## **Key Highlights**
- Removed FTB Backups due to major world generation reverting issues
- Tweaked some recipes for Diesel Generators and Create Resource Vents, allowing for a more balanced feeling.
- Updated a few mods improving stability and compatibility.
- Continued stability and polish following the extensive changes introduced in **[v3.0.0 Highlights](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.0.0_Highlights.md)**.
