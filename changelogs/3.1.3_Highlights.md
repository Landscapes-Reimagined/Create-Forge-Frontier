# **Modpack Patch Notes: Version 3.1.3**
**Release Date:** August 28th, 2026

### *The Final Frontier*

## **Overview**
Version **3.1.3** is a maintenance, compatibility, and performance-focused update that continues refining *The Final Frontier* without introducing a major progression overhaul. This release expands the pack's optimization stack with new client and server performance tools, improves compatibility across Create and several supporting mods, and resolves a collection of recipe, loot table, tag, configuration, and usability issues.

The update also introduces new Create-integrated gameplay options through **Apokinetics** and **Create: Unbreakable Tools**, while additional compatibility utilities strengthen integration between existing systems. Several redundant or conflicting mods have been removed to improve stability and maintainability.

---

## **Key Highlights**
- **Expanded Performance Stack**: Added Embeddium Extra, Farsight, Geckolib Better FPS, Sightline, Stellar Create Optimization, and Swift Gen to improve rendering, chunk generation, entity rendering, Create machinery, and general client performance.
- **New Create Integrations**: Added Apokinetics and Create: Unbreakable Tools, expanding Create-based progression with Machine Gem integration and the Irromolding item.
- **Compatibility Improvements**: Added CFM Refurbished: Watt About Power?, Client Mixin Intercept, Advanced Core Info, and other supporting utilities to improve compatibility and stability.
- **Performance Mod Cleanup**: Removed Bobby Reforged and Chloride due to compatibility conflicts with the current optimization stack, while Colorwheel Patcher was removed after its functionality became redundant.
- **Create: Buzzy Bees Removal**: Removed Create: Buzzy Bees due to broken recipe catalyst integration that left a significant portion of its content inaccessible through normal progression.
- **Recipe & Progression Fixes**: Restored the AE2 Spatial Storage Component recipe, corrected Create Fluid and Create: Dragons Plus processing recipes, and added custom Create-based recipes for the Apotheosis Boss Summoner and Irromolding.
- **Loot & Structure Improvements**: Fixed the Alex's Mobs Soul Vulture loot table, added missing Apokinetics block loot tables, and added Chromatic Compound to Tinker's Citadel and Workshop vault loot pools.
- **Tag Compatibility**: Expanded Create Wrench compatibility across numerous blocks and added missing Curios tags for supported Terminal and Ring items.
- **Resource Pack Updates**: Updated Sophisticated Backpacks and Sophisticated Storage Tier and Stack Upgrade textures to better represent their required crafting resources.
- **JEI & Configuration Refinements**: Updated JEI sorting and blacklist configuration and disabled conflicting Create: Dragons Plus Freezing recipes.
- **Improved Item Information**: Added custom tooltips for the Apotheosis Boss Summoner and Irromolding item.
- Continued refining the systems introduced in **[v3.1.0 Highlights](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.1.0_Highlights.md)**.
