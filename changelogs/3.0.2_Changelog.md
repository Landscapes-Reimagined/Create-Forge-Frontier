## **Mod Additions**
- **[Nebula Mod](https://www.curseforge.com/minecraft/mc-mods/nebula-mod)**: Lightweight performance optimization mod that improves FPS, reduces stuttering, and enhances rendering and entity performance for a smoother Minecraft experience.
- **[Create: Nowheel](https://www.curseforge.com/minecraft/mc-mods/create-nowheel)**: Improves performance by preventing hidden Create contraptions and machines from rendering until they become visible.
- **[More Overlays Updated](https://www.curseforge.com/minecraft/mc-mods/more-overlays-updated)**: Adds configurable overlays for light levels, chunk borders, and item searches to provide helpful visual information while playing.

## Mod Removals
- **Light Overlays**: Replaced with More Overlays Updated, providing improved overlay functionality with additional features and expanded customization options.
- **Neruina**: Removed due to stability issues that caused harmless entities to be falsely identified as problematic and prevented from ticking, eventually resulting in server crashes as these false positives accumulated.

## **KubeJS & Script Changes**
### Startup Script Updates
- **kubejs\startup_scripts\Forge Frontier**: New item, **ppfluids:blank fluid module**, used in updated upgrade recipes

### Server Script Updates
- **kubejs\server_scripts\Compat\Create Forge Frontier**: Updated Rocket Casing Recipes to where starting ingredient is now the ingot corresponding to the casing type; Removed vanilla iron ingot to industrial iron block due to Dream's & Desires recipes; Removed Compost and Water Liquid Fertilizer recipe
- **kubejs\server_scripts\Compat\Tags\Block_Tags**: Remove Create Wrenchable Tag from Sophisticated Storage Blocks due to major bug with autopackaging mechanics; Added Metallurgy Blocks to Create Fluid tap fillable tag
- **kubejs\server_scripts\Mod Adjustments\Toms Simple Storage**: Converted old Datapack into KubeJS scripts due to loading issues
- **kubejs\server_scripts\Mod Adjustments\Immersive Aircrafts**: Converted old Datapack into KubeJS scripts due to loading issues
- **kubejs\server_scripts\Mod Adjustments\Apotheosis**: Updated Material recipes to where dimension block is the starting ingredient to remove any possible recipe conflicts
- **kubejs\server_scripts\Mod Adjustments\Create Metallurgy**: Updated Refractory Mortar recipe to be heated to remove any possible conflicts with other recipes
- **kubejs\server_scripts\Mod Adjustments\Pretty Pipes**: Updated Pretty Pipe Fluid starter upgrades to use new blank fluid module to remove any possible recipe conflicts
