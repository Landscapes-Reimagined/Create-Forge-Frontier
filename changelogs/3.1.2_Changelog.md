# **Create - Forge Frontier: Version 3.1.2**
### *The Final Frontier*

### **Introduction**

Version **3.1.2** is a maintenance and compatibility update focused on refining the systems introduced in Version **3.1.0** through targeted quest fixes, recipe corrections, configuration adjustments, and updated mods.

This release addresses several smaller issues across the pack, including a broken Alex's Caves quest task, inconsistent Sophisticated Storage and Sophisticated Backpacks Conversion Upgrade recipes, duplicate Create Mob Spawners recipes, and Ad Astra oil compatibility. Flux Networks chunkloading has also been disabled to keep chunkloading behavior more controlled across the pack.

Seven mods have also been updated to improve compatibility, stability, and long-term maintainability while preserving the progression and gameplay experience established in recent releases.

---

### **Overview**

Version **3.1.2** focuses on polishing existing content rather than introducing major new progression systems. Several recipes and data files have been corrected for greater consistency, including Conversion Upgrades for Sophisticated Backpacks and Sophisticated Storage, Create Mob Spawners spawning recipes, and Ad Astra's Oil-to-Fuel processing recipe.

Quest and configuration refinements are also included. The Alex's Caves Candicorn quest task has been fixed, Sophisticated Storage's Silicon naming has been clarified as Raw Silicon, and Flux Networks chunkloading has been disabled.

Alongside these pack-level changes, seven mods have been updated, including Create: Enchantment Industry, Create: Dragons Plus, Chunksending, Create Compatible Storage, Sophisticated Backpacks, Sophisticated Core, and Structurify. Together, these changes continue improving compatibility and reliability without altering the core progression established in Version **3.1.0**.
