# **Modpack Patch Notes: Version 3.1.4**
**Release Date:** August 28th, 2026

### *The Final Frontier*

## **Overview**

Version **3.1.4** is a maintenance and stability update focused on improving memory usage, server performance, and overall compatibility following issues identified during continued testing of Version **3.1.3**.

This release removes four mods associated with stability, memory usage, performance, or compatibility concerns while continuing to update and refine the pack's technical foundation. These changes are intended to provide a more reliable experience during longer play sessions on both dedicated servers and singleplayer worlds without altering the progression established throughout *The Final Frontier*.

---

## **Key Highlights**
- **Improved Memory Stability**: Removed mods identified as potential contributors to excessive memory usage to improve long-session reliability for both servers and singleplayer worlds.
- **Apokinetics Removed**: Removed due to stability and compatibility concerns, with several features not functioning as intended within the modpack.
- **Chunk Performance Improvements**: Removed Chunksending due to incompatibility with Krypton Reforged and concerns surrounding chunk handling and server performance.
- **Optimization Cleanup**: Removed Smoothchunk after testing showed minimal measurable performance improvements alongside potential memory usage concerns.
- **CFM WAP Removed**: Removed after being identified as a potential contributor to excessive memory usage and possible memory leaks.
- **Updated Mods**: Updated several mods to their latest compatible versions to continue improving stability, compatibility, and performance throughout the pack.
- Continued refining the systems introduced in **[v3.1.0 Highlights](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.1.0_Highlights.md)**.
