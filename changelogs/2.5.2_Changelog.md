# 🛠️ **Create - Forge Frontier: Version 2.5.2 Update**  
### *Patch Revision*

## 📖 Introduction  
Version **2.5.2** is a **stability and refinement update** for *Create - Forge Frontier*, focusing on polishing systems introduced in 2.5.0 and improving gameplay consistency.  
This patch resolves recipe inconsistencies, expands metallurgy support, and rebalances quests for smoother progression.

---

## 🔧 Overview  
- General performance and compatibility improvements.  
- Overhauled Metallurgy integration for smoother alloy production and casting recipes.  
- Adjusted progression quests for AE2, Cataclysm, and Create systems.  
- New balance adjustments for Create Resource Vents and automation structures.  
- Updated configuration defaults and restored world height settings.

## ⚙️ KubeJS & Script Changes  

### 🛠️ Server Script Changes 
- **Create Metallurgy** – Added missing Create DD Bronze compat recipes; removed duplicates; added new basin and table casting recipes; implemented new casing recipe system.

- **Create Additions & Synthetics** – Converted *Molten Andesite* handling to match Metallurgy-style processing.  
- **Crafts & Additions** – Added Rolling Mill recipes for *Powah* and *Ad Astra* rods.
