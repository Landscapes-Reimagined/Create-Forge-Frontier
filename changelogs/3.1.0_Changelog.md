## Mod Removals
- **Create: Dragons Plus (Unofficial Backport)**: Replaced with the official Create: Dragons Plus backport for improved compatibility and long-term support.
- **EC Apotheosis Plugin**: Removed due to server stability issues caused when applying Apotheosis data to items added through Expanded Compat.
- **Every Compat: Wood Good**: Removed to reduce loading times and memory usage, improving overall modpack performance.
- **Every Compat: Stone Zone**: Removed to reduce loading times and memory usage, improving overall modpack performance.
