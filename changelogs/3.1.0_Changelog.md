# **Create - Forge Frontier: Version 3.1.0**
### *The Final Frontier*

### **Introduction**
Version **3.1.0** marks the next major step in the continued development of *The Final Frontier*, expanding storage and automation options while improving performance, compatibility, and progression throughout the pack.

The centerpiece of this update is the **return of Applied Energistics 2**, now reintroduced as an alternative late-game storage and automation system alongside Refined Storage. AE2 and its supported addons have been carefully integrated with custom recipes, Create compatibility, updated textures, and a reworked quest chapter to better align with Forge Frontier's progression and balance.

This release also brings significant changes to **Create: Enchantment Industry**, expands compatibility with **Apotheosis**, introduces several new Create-focused integrations and quality-of-life additions, and removes resource-intensive compatibility mods to improve startup times, memory usage, and overall performance.

---

### **Overview**
Version **3.1.0** focuses on expanding player choice while strengthening the Create-centered progression that defines Forge Frontier.

**Applied Energistics 2** returns with a significantly expanded integration featuring AdvancedAE, ExtendedAE, MEGA Cells, AE2 Things, wireless terminals, and numerous other addons. New Create integrations connect ME networks with mechanical crafting, package logistics, Schematicannon construction, stock networks, and other automation systems. AE2 progression has also been rebalanced specifically for Forge Frontier, ensuring it serves as a powerful late-game alternative without replacing Refined Storage as the pack's more approachable storage option.

The **Create: Enchantment Industry** integration has also been updated, resulting in adjustments throughout Apotheosis, dimensional progression, quest rewards, custom assets, and several recipes. Additional Apotheosis crushing recipes further expand the connection between combat progression and Create automation.

Performance and stability remain an important focus of this release. **Every Compat: Wood Good** and **Every Compat: Stone Zone** have been removed to reduce loading times and memory usage, while replacement recipes preserve important crafting compatibility. The **EC Apotheosis Plugin** has also been removed following server stability issues.

Alongside these larger changes, Version **3.1.0** introduces new building and quality-of-life options, reorganizes portions of the questbook, updates rocket component progression, expands Create compatibility, and includes numerous recipe, configuration, and scripting improvements.

## Mod Additions
- **[Framework](https://www.curseforge.com/minecraft/mc-mods/framework)**: Provides a shared library of systems and utilities required by MrCrayfish's mods.
- **[MrCrayfish's Furniture Mod: Refurbished](https://www.curseforge.com/minecraft/mc-mods/refurbished-furniture)**: Adds a redesigned collection of functional furniture, decorations, appliances, and other interactive blocks.
- **[Create: Chipped](https://www.curseforge.com/minecraft/mc-mods/create-chipped)**: Expands Chipped compatibility by adding decorative variants for stone types introduced by Create.
- **[Mech Trowel](https://www.curseforge.com/minecraft/mc-mods/mech-trowel)**: Adds an advanced building trowel with randomized block placement, customizable palettes, gradients, and building wand functionality.
- **[Ender Lead](https://www.curseforge.com/minecraft/mc-mods/ender-lead)**: Adds a reusable Ender Lead that allows players to capture, transport, and release entities more easily.
- **[Create: Dragons Plus](https://www.curseforge.com/minecraft/mc-mods/create-dragons-plus)**: Expands Create with additional fan processing mechanics, fluid utilities, quality-of-life features, and compatibility with supported addons.
- **[AdvancedAE](https://www.curseforge.com/minecraft/mc-mods/advancedae)**: Expands Applied Energistics 2 with advanced automation, crafting, storage, and quality-of-life features for ME networks.
- **[GuideME](https://www.curseforge.com/minecraft/mc-mods/guideme)**: Provides the guidebook framework used by Applied Energistics 2 and other mods for interactive documentation and in-game guides.
- **[Applied Energistics 2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2)**: Adds an advanced digital storage and automation system centered around ME networks, autocrafting, logistics, and resource management.
- **[AE2 Import Export Card](https://www.curseforge.com/minecraft/mc-mods/ae2-import-export-card)**: Adds configurable Import and Export Cards that automatically transfer items between a player's inventory and their ME network.
- **[AE2 Things](https://www.curseforge.com/minecraft/mc-mods/ae2-things-forge)**: Expands Applied Energistics 2 with additional storage cells, an advanced inscriber, and a crystal growth chamber.
- **[MEGA Cells](https://www.curseforge.com/minecraft/mc-mods/mega-cells)**: Adds extremely high-capacity storage cells and a dedicated progression system for expanding large Applied Energistics 2 networks.
- **[ME Requester](https://www.curseforge.com/minecraft/mc-mods/merequester)**: Adds automated requesters that maintain configurable quantities of items within an Applied Energistics 2 network.
- **[ExtendedAE](https://www.curseforge.com/minecraft/mc-mods/ex-pattern-provider)**: Expands Applied Energistics 2 with advanced machines and components designed to improve storage, processing, and autocrafting.
- **[AE2 QoL Recipes](https://www.curseforge.com/minecraft/mc-mods/ae2-qol-recipes)**: Adds additional cable conversion recipes that make it easier to repurpose unused Applied Energistics 2 cables.
- **[Applied Energistics 2 Wireless Terminals](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2-wireless-terminals)**: Adds wireless versions of several AE2 terminals with options for long-range and cross-dimensional ME network access.
- **[Polymorphic Energistics](https://www.curseforge.com/minecraft/mc-mods/polymorphic-energistics)**: Adds Polymorph compatibility to Applied Energistics 2, allowing players to select between conflicting crafting recipes.
- **[Create Stock Bridge](https://www.curseforge.com/minecraft/mc-mods/create-stock-bridge)**: Connects Create's stock logistics network with Applied Energistics 2, allowing both systems to exchange and request stored items.
- **[Create Applied Kinetics](https://www.curseforge.com/minecraft/mc-mods/create-applied-kinetics)**: Integrates Create and Applied Energistics 2 with additional mechanics for connecting automation, logistics, and kinetic systems.
- **[Schematic Energistics](https://www.curseforge.com/minecraft/mc-mods/schematic-energistics)**: Connects Create's Schematicannon to Applied Energistics 2, allowing building materials to be supplied directly from an ME network.
- **[Applied Create](https://www.curseforge.com/minecraft/mc-mods/applied-create)**: Bridges Create and Applied Energistics 2 with mechanical crafting automation and the ability to transmit rotational stress through ME networks.
- **[Applied Schematicannon](https://www.curseforge.com/minecraft/mc-mods/applied-schematicannon)**: Allows Create's Schematicannon to retrieve building materials and gunpowder directly from an Applied Energistics 2 ME network.
- **[AE Infinity Booster](https://www.curseforge.com/minecraft/mc-mods/aeinfinitybooster)**: Adds upgrade cards that extend AE2 wireless terminal access across unlimited distances and dimensions.
- **[Create Package](https://www.curseforge.com/minecraft/mc-mods/create-package)**: Connects Applied Energistics 2 autocrafting with Create machines to support automated Sequenced Assembly processing.
- **[Re-Exposer](https://www.curseforge.com/minecraft/mc-mods/re-exposer)**: Allows Refined Storage networks to expose their item and fluid storage to external systems such as Applied Energistics 2 storage buses.

## Mod Removals
- **Create: Dragons Plus (Unofficial Backport)**: Replaced with the official Create: Dragons Plus backport for improved compatibility and long-term support.
- **EC Apotheosis Plugin**: Removed due to server stability issues caused when applying Apotheosis data to items added through Expanded Compat.
- **Every Compat: Wood Good**: Removed to reduce loading times and memory usage, improving overall modpack performance.
- **Every Compat: Stone Zone**: Removed to reduce loading times and memory usage, improving overall modpack performance.

## **KubeJS & Script Changes**
### **Asset Changes**
- **Assets\Create Dragons Plus**: Removed outdated language files that are no longer required following the Create: Dragons Plus update.
- **Assets\Forge Frontier**: Removed legacy Hyper Experience Nugget and Block assets following the Create: Enchantment Industry update.
- **Assets**: Added new Create-compatible textures for Applied Energistics 2 and its supported addons.

### **Server Script Changes**
- **Server Scripts\Compat\Create Forge Frontier\Forge Rocket**: Updated recipes for the Arcane Calibration Matrix and Forge Rocket Tank to reflect the latest progression changes.
- **Server Scripts\Compat\Metallurgy**: Removed legacy Hyper Experience compatibility recipes that are no longer required.
- **Server Scripts\Compat\Minecraft**: Added custom Bookshelf and Beehive compatibility recipes following the removal of Every Compat: Wood Good.
- **Server Scripts\Mod Adjustments\Apotheosis**: Added new crushing recipes for Apotheosis gems and armor.
- **Server Scripts\Mod Adjustments\End Remastered**: Updated the Undead Soul mixing recipe to use Hyper Experience Nuggets instead of Bottles o' Enchanting following the Create: Enchantment Industry update.
- **Server Scripts\Mod Adjustments\Create More Additions**: Removed conflicting Electrum recipes to prevent recipe conflicts.
- **Server Scripts\Mod Adjustments**: Added new Create compatibility recipes for Applied Energistics 2 and its supported addons, along with recipe removals and adjustments for progression balancing.
