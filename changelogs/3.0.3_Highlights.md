# **Modpack Patch Notes: Version 3.0.3**
**Release Date:** July 22nd, 2026

### *The Final Frontier*

#### **⚠️ Important: Read [v3.0.0 Highlights](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.0.0_Highlights.md) and [v3.0.0 Changelog](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.0.0_Changelog.md) before updating**

Version **3.0.3** is the second maintenance update following *The Final Frontier*. This release focuses on bug fixes, compatibility improvements, quest corrections, and updated mods without changing progression or requiring a new world.

---

## **Overview**
Version **3.0.3** builds upon the foundation established in **Version 3.0.0**, improving stability, compatibility, and overall polish while maintaining full world compatibility with existing **3.0.0** saves.

---

## **Key Highlights**
- Removed Create Teleporters Resource Pack and mod due to missing loot tables and more.
- Updated several core mods for improved stability and compatibility..
- Continued stability and polish following the extensive changes introduced in **[v3.0.0 Highlights](https://github.com/Landscapes-Reimagined/Create-Forge-Frontier/blob/main/changelogs/3.0.0_Highlights.md)**.
