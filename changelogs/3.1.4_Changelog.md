# **Create - Forge Frontier: Version 3.1.4**
### *The Final Frontier*

### **Introduction**

Version **3.1.4** is a maintenance and stability update focused on addressing several performance, memory usage, and compatibility concerns identified during continued testing of Version **3.1.3**.

This release removes several mods that were found to be unstable, potentially contributing to excessive memory usage, incompatible with other optimization systems, or providing little measurable benefit to the pack. These changes are intended to improve long-term stability for both singleplayer worlds and dedicated servers while reducing unnecessary overhead.

No major progression or world generation changes are introduced in this release, and existing worlds from Version **3.0.0 and later** remain fully compatible.

---

### **Overview**

Version **3.1.4** focuses primarily on strengthening the performance and stability of *Create - Forge Frontier* following issues identified during testing and community server operation.

Four mods have been removed as part of this update. **Apokinetics** has been removed due to stability and compatibility concerns with several features not functioning as intended within the pack. **CFM WAP** and **Smoothchunk** have been removed after being identified as potential contributors to excessive memory usage, with Smoothchunk also providing minimal measurable performance improvements. **Chunksending** has been removed due to incompatibility with Krypton Reforged and concerns surrounding chunk handling and server performance.

Alongside these removals, the update continues refining the pack's technical foundation through updated mods and compatibility improvements. The overall goal of Version **3.1.4** is to reduce unnecessary overhead, improve long-session reliability, and provide a more consistent experience across both dedicated servers and singleplayer worlds.

Together, these changes strengthen the technical foundation of *The Final Frontier* while preserving the core gameplay and progression established in Version **3.1.0**.

## Mod Removals
- **Apokinetics**: Removed due to stability and compatibility concerns, as several features are not currently functioning as intended within the modpack and can significantly impact gameplay.
- **CFM WAP**: Removed after being identified as a potential contributor to excessive memory usage and possible memory leaks.
- **Chunksending**: Removed due to incompatibility with Krypton Reforged, which could negatively impact chunk handling and overall server performance.
- **Smoothchunk**: Removed after being identified as a potential contributor to excessive memory usage, while providing minimal measurable performance improvements within the pack.
