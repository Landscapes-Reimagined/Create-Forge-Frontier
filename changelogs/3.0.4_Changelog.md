## **Mod Additions**
- **[Create: Dragons Plus (unofficial backport)](https://www.curseforge.com/minecraft/mc-mods/create-dragons-plus-unofficial-1-20-1-backport-1)**: Backports the shared utilities, quality-of-life features, and compatibility systems required by Create: Enchantment Industry and other Dragons Plus addons to Minecraft 1.20.1. 
- **[JEIOptimizer](https://www.curseforge.com/minecraft/mc-mods/jeioptimizer)**: Optimizes JEI's ingredient indexing to improve loading performance and reduce connection times on heavily modded instances.
- **[Concurent Chunk Management Engine - Forge](https://www.curseforge.com/minecraft/mc-mods/concurent-chunk-management-engine-forge)**: Improves performance by parallelizing chunk generation, loading, saving, and lighting to provide faster world generation and smoother exploration.
- **[Refined Storage Universal Fluid Fix](https://www.curseforge.com/minecraft/mc-mods/refined-storage-universal-fluid-fix)**: Adds virtual fluid bucket support for Refined Storage, allowing fluids without bucket items to be used in importer and exporter filters.

## Mod Removals
- **Concurrent Chunk Management Engine for Forge -The Twilight Forest fix**: Replaced with more frequently updated fork **Concurent Chunk Management Engine - Forge**
- **Nebula Mod**: Overtime, running this mod causes rendering issues where blocks would not be synced up properly.

## Quest Fixes
- **Basic Dimensions Chapter**: Updated Tasks and Description for Nether Remastered Seal Quest to make it easier for players to understand.
- **Dimensional Progression Chapter**: Updated Description for End Quest to explain that you must use End Remastered Eyes in locating the stronghold since vanilla Ender Eyes do not work.

## **KubeJS & Script Changes**
### Asset Updates
- **kubejs\assets\extrastorage\lang**: Updated the names of the Crafters to match the updated recipes
- **kubejs\assets\create_dragons_plus\lang**: Backpacked official Language Files from 1.21.1 to newly added Backport mod

### Data Updates
- **kubejs\data\create_dd\loot_tables**: Added missing loot tables for Rubber Leaves, matching the formatting of vanilla leaves
- **kubejs\data\createaddition\recipes\liquid_burning**: Added new custom Liquid Burning for Superheated Lava from Create QOL

### Server Script Updates
- **kubejs\server_scripts\Compat\Tags**: Added missing Create Cobblestone Tag for Alex's Caves Limestone; Added missing create wrench tag for RS Cable; Updated Enchantment Industry Ink tag to fix conflicting recipe with Create Dragon's Plus; Created new Create Resource Stone tag for all of the packs resource stones; Updated Rare Packages Tag to include new Create Dragon's Plus packages; Added missing Forge Wrench Tag to Refined Storage Wrench.
- **kubejs\server_scripts\Compat\Create Metallurgy\Washing_Recipes**: Updated Dirty Resonite Dust washing byproduct to match percentage of others and also changed it from Warden Carapace to Sculk Crystalline Flour; Switched out Dreams and Desires Steel Nuggets for Ad Astra Steel nuggests
