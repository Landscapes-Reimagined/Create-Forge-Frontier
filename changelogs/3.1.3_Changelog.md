# **Create - Forge Frontier: Version 3.1.3**
### *The Final Frontier*

### **Introduction**

Version **3.1.3** is a maintenance, compatibility, and performance-focused update that continues refining the systems established throughout *The Final Frontier*. This release expands the pack's optimization stack, introduces several new compatibility and quality-of-life mods, and addresses a range of recipe, loot table, tag, configuration, and client-side issues.

Several additions specifically target client and server performance, including **Embeddium Extra**, **Farsight**, **Geckolib Better FPS**, **Sightline**, **Stellar Create Optimization**, and **Swift Gen**. New gameplay and compatibility additions also include **Apokinetics**, **Create: Unbreakable Tools but just the item**, and **CFM Refurbished: Watt About Power?**, alongside supporting utilities intended to improve stability and usability.

This update also removes several mods whose functionality was either no longer required or conflicted with the pack's current performance and compatibility stack. Together with extensive KubeJS and configuration refinements, Version **3.1.3** continues improving the reliability, consistency, and long-term maintainability of *Create - Forge Frontier* without introducing a major progression overhaul.

---

### **Overview**

Version **3.1.3** places a strong emphasis on performance, compatibility, and progression consistency. Thirteen mods have been added, including new optimization tools for rendering, chunk generation, GeckoLib entities, Create machinery, and client-side usability. Four mods have been removed to resolve compatibility concerns, eliminate redundant functionality, and address inaccessible content.

Pack-level refinements include updated **Sophisticated Backpacks** and **Sophisticated Storage** resource-pack textures, revised JEI sorting and blacklist configuration, and the removal of conflicting **Create: Dragons Plus** Freezing recipes. KubeJS data updates restore the **Alex's Mobs Soul Vulture** loot table, add missing **Apokinetics** block loot tables, correct **Create Fluid** and **Create: Dragons Plus** recipes, and add Chromatic Compound to **Integrated Dungeons and Structures** Tinker's Citadel and Workshop vault loot pools.

Additional scripting improvements restore the **AE2 Spatial Storage Component** recipe, expand Create Wrench compatibility across supported blocks, add missing Curios tags, and introduce custom Create-based recipes for the **Apotheosis Boss Summoner** and **Irromolding**. New tooltips have also been added to both items to better communicate their functionality and progression requirements.

Together, these changes strengthen the technical foundation of *The Final Frontier* while preserving the core gameplay and progression established in Version **3.1.0**.

## Mod Additions

- [Advanced Core Info (ACI)](https://www.curseforge.com/minecraft/mc-mods/advanced-core-info): A shared core library that provides common functionality for Advanced Loot Info and Advanced Worldgen Info, including plugin discovery, tooltip trees, and server-to-client data handling.
- [Apokinetics](https://www.curseforge.com/minecraft/mc-mods/apokinetics): Integrates Apotheosis-style progression with Create machinery, allowing supported machines to be enhanced with specialized Machine Gems for additional factory customization.
- [CFM Refurbished: Watt About Power?](https://www.curseforge.com/minecraft/mc-mods/cfm-wap): Adds compatibility between MrCrayfish's Furniture Mod: Refurbished and external energy systems through a circuit breaker that can power Refurbished's electricity network.
- [Client Mixin Intercept](https://www.curseforge.com/minecraft/mc-mods/client-mixin-intercept): A server-side compatibility utility designed to intercept problematic client-only Mixin injections that could otherwise prevent dedicated servers from starting.
- [Create: Unbreakable Tools but just the item](https://www.curseforge.com/minecraft/mc-mods/create-unbreakable-tools-but-just-the-item): Adds the Irromolding item, providing a way to make compatible tools permanently unbreakable through an anvil-based upgrade process.
- [Cubes Without Borders](https://www.curseforge.com/minecraft/mc-mods/cubes-without-borders): Adds configurable borderless fullscreen support, improving multitasking and multi-monitor usability without requiring Minecraft to minimize when switching applications.
- [Embeddium Extra](https://www.curseforge.com/minecraft/mc-mods/rubidium-extra): Extends Embeddium with additional graphics, performance, and quality-of-life options based on features from Sodium Extra.
- [Farsight](https://www.curseforge.com/minecraft/mc-mods/farsight): Allows the client to retain previously received chunks beyond the server's configured view distance, providing greater visible render distance without increasing the server's view-distance setting.
- [Geckolib Better FPS](https://www.curseforge.com/minecraft/mc-mods/geckolib-better-fps): Optimizes the rendering of GeckoLib-powered entities to reduce their rendering overhead and improve client-side performance.
- [Just Zoom](https://www.curseforge.com/minecraft/mc-mods/just-zoom): Adds a configurable client-side zoom feature with smooth zooming, adjustable magnification, and normalized mouse sensitivity.
- [Sightline](https://www.curseforge.com/minecraft/mc-mods/sightline): Improves client-side performance by reducing unnecessary rendering of content outside the player's visible view.
- [Stellar Create Optimization](https://www.curseforge.com/minecraft/mc-mods/stellarcreateoptimization): Provides performance optimizations specifically for Create 6.0.x, targeting factory rendering, particles, block entities, shaders, and server tick performance.
- [Swift Gen](https://www.curseforge.com/minecraft/mc-mods/swiftgen): Improves terrain generation performance to help reduce the processing overhead associated with generating new chunks.

## Mod Removals

- **Bobby Reforged**: Removed due to compatibility conflicts with other performance and chunk-rendering optimizations in the pack that could contribute to client-side instability and crashes.
- **Chloride**: Removed due to compatibility conflicts with the pack's existing performance stack and issues affecting window display and formatting behavior.
- **Colorwheel Patcher**: Removed because its functionality is no longer required, as the primary mod now provides the necessary compatibility patches for the included shader packs.
- **Create: Buzzy Bees**: Removed due to broken recipe catalyst integration that left a significant portion of the mod's content inaccessible through normal progression.

---

## Config Updates
- **Create: Dragons Plus Server**: Disabled conflicting Freezing recipes through the server configuration to prevent recipe conflicts with the pack's existing processing systems.
- **JEI**: Updated the mod sorting order and blacklist to account for the latest mod additions and maintain a cleaner recipe browsing experience.
- **Open Loader**: Updated the custom resource packs for **Sophisticated Backpacks** and **Sophisticated Storage**, refreshing Tier and Stack Upgrade textures to better represent the resources required for each upgrade.
- **Server Core**: Updated Settings to improve Server View, Simulation, and Chunk Tick Distance

## KubeJS Updates

### Data Updates
- **Alex's Mobs**: Fixed the broken Soul Vulture mob loot table to restore its intended drops.
- **Apokinetics**: Added missing block loot tables to ensure affected blocks properly drop their intended items when broken.
- **Create: Dragons Plus**: Corrected Dye Catalyst block tags to allow the affected recipes to use their intended fan-processing methods instead of requiring fluid-based processing.
- **Create Fluid**: Updated the Breeze Rod from Blaze Rod recipe for compatibility with the pack's progression and fixed the broken Honeycomb Mold recipe.
- **IDAS**: Added Chromatic Compound to the Tinker's Citadel and Tinker's Workshop vault loot pools, providing an additional method of obtaining the material and making Seal of the Underworld progression more accessible.

### Client Script Updates
- **Apotheosis**: Added a custom tooltip to the Boss Summoner to provide additional information about its functionality.
- **Create: Unbreakable Tools**: Added a custom tooltip to the Irromolding item to better explain its functionality and enchantment restrictions.

### Server Script Updates
- **Compat/Tags/Block Tags**: Added missing Create wrenchable tags to numerous compatible blocks, improving consistency when interacting with them using the Wrench.
- **Compat/Tags/Item Tags**: Added missing Curios tags for supported Terminal and Ring items to improve compatibility with their intended equipment slots.
- **Mod Adjustments/AE2**: Corrected an unintended recipe removal affecting the Spatial Storage Component, restoring access to its intended recipe.
- **Mod Adjustments/Apotheosis**: Added a custom recipe for the Boss Summoner, integrating its crafting progression more closely with the pack's Create-based automation systems.
- **Mod Adjustments/Create: Unbreakable Tools**: Added a custom recipe for the Irromolding item, integrating it into the pack's custom Create-based progression.
