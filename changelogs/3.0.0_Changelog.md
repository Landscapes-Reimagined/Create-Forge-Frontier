## **Mod Additions**
- **[Create Utilities J](https://www.curseforge.com/minecraft/mc-mods/create-utilities-j)**: A maintained Create addon that adds void-themed blocks for wireless transfer of rotation, items, and fluids.  
- **[Edivad Lib](https://www.curseforge.com/minecraft/mc-mods/edivadlib)**: A shared library that reduces duplicate code and improves development and bug-fix efficiency across supported mods.  
- **[Extra Storage](https://www.curseforge.com/minecraft/mc-mods/extrastorage)**: Expands Refined Storage with additional blocks, including more advanced crafting options.  
- **[Flux Networks](https://www.curseforge.com/minecraft/mc-mods/flux-networks)**: Adds wireless energy networks compatible with most major Forge power systems.  
- **[Refined Storage Mixin](https://www.curseforge.com/minecraft/mc-mods/refined-storage-mixin)**: Improves Refined Storage performance by reducing server lag and preventing async deadlocks during chunk unloads.  
- **[ParCool](https://www.curseforge.com/minecraft/mc-mods/parcool)**: Adds enhanced movement and parkour actions to improve traversal and mobility.  
- **[ParCool Compatibility Addon](https://www.curseforge.com/minecraft/mc-mods/parcool-compatibility-addon)**: Adds compatibility support between ParCool and other mods.  
- **[Regions Unexplored Expansion](https://www.curseforge.com/minecraft/mc-mods/regions-unexplored-expansion)**: Reworks vanilla biomes to better match the visual style of Regions Unexplored.  
- **[Ad Astra Tools](https://www.curseforge.com/minecraft/mc-mods/ad-astra-more-tools)**: Expands Ad Astra with additional tools and related progression content.  
- **[Ad Astra More Structures](https://www.curseforge.com/minecraft/mc-mods/ad-astra-more-structures)**: Adds new structures, dungeons, and bosses to Ad Astra planets.  
- **[Alex's Caves Better Combat](https://www.curseforge.com/minecraft/mc-mods/alexs-caves-better-combat)**: Adds Better Combat compatibility for Alex’s Caves content.  
- **[Attribute Setter](https://www.curseforge.com/minecraft/mc-mods/attribute-setter)**: Allows default entity and item attributes to be adjusted through datapacks.  
- **[Better Combat](https://www.curseforge.com/minecraft/mc-mods/better-combat-by-daedelus)**: Overhauls melee combat with improved animations and systems inspired by action-focused gameplay.  
- **[Better Farmers Combat](https://www.curseforge.com/minecraft/mc-mods/better-farmers-combat)**: Adds Farmer’s Delight compatibility support for Better Combat.  
- **[Cable Tiers](https://www.curseforge.com/minecraft/mc-mods/cable-tiers)**: Adds higher-tier versions of key Refined Storage and RSRequestify components for improved scaling.  
- **[Cataclysm & BetterCombat - Compatibility](https://www.curseforge.com/minecraft/mc-mods/cataclysm-bettercombat-compatibility)**: Provides compatibility between L_Ender’s Cataclysm and Better Combat.  
- **[Crafting Recipes Exporter](https://www.curseforge.com/minecraft/mc-mods/crafting-recipe-exporter)**: Adds a GUI that exports recipes into JSON or KubeJS formats.  
- **[Create Access Denied](https://www.curseforge.com/minecraft/mc-mods/create-access-denied)**: Adds access management tools for Create logistics stock management systems.  
- **[Create Easy Filling](https://www.curseforge.com/minecraft/mc-mods/create-easyfilling)**: Allows Create Spouts to directly fill Create Stuff ‘N Additions tank items.  
- **[Create Factory](https://www.curseforge.com/minecraft/mc-mods/create-factory)**: Adds additional food and processing content designed around Create automation.  
- **[Create More Additions](https://www.curseforge.com/minecraft/mc-mods/create-more-additions)**: Expands Create Crafts & Additions with new ores, recipes, and supporting content.  
- **[Create Pillagers Arise](https://www.curseforge.com/minecraft/mc-mods/create-pillager-arise)**: Adds new pillager-defended structures to world generation.  
- **[Create Ratatouille](https://www.curseforge.com/minecraft/mc-mods/create-ratatouille)**: Adds agricultural and food-processing machines designed for Create production lines.  
- **[Create Structures](https://www.curseforge.com/minecraft/mc-mods/create-structures)**: Adds Create-themed industrial structures that naturally generate in the Overworld.  
- **[Create Structures Arise](https://www.curseforge.com/minecraft/mc-mods/create-structures-arise)**: Adds a large set of Create-themed structures to world generation.  
- **[Create Cobblestone](https://www.curseforge.com/minecraft/mc-mods/create-cobblestone)**: Adds an SU-powered cobblestone generator designed to be frame-safe for automation setups.  
- **[Create Contraption Terminals](https://www.curseforge.com/minecraft/mc-mods/create-contraption-terminals)**: Enables Tom’s Simple Storage terminals to function on Create contraptions.  
- **[Create Diesel Generators](https://www.curseforge.com/minecraft/mc-mods/create-diesel-generators)**: Adds oil refining and diesel-based power generation systems for Create.  
- **[Create Fishery Industry](https://www.curseforge.com/minecraft/mc-mods/create-fishery-industry)**: Expands Create with aquatic automation systems including fishing, diving, and processing mechanics.  
- **[Create Threaded Trains](https://www.curseforge.com/minecraft/mc-mods/create-threaded-trains)**: Improves Create railway performance by running network calculations on a separate thread.  
- **[Create Transmission](https://www.curseforge.com/minecraft/mc-mods/create-transmission)**: Adds a Transmission Chain block for cleaner belt power distribution.  
- **[Cristel Lib](https://www.curseforge.com/minecraft/mc-mods/cristel-lib)**: Provides a library for streamlined structure configuration and runtime datapack support.  
- **[Expanded Combat](https://www.curseforge.com/minecraft/mc-mods/expanded-combat)**: Expands combat variety with new gear such as shields, arrows, bows, gauntlets, and weapons.  
- **[EC Advanced Netherite Plugin](https://www.curseforge.com/minecraft/mc-mods/ec-advanced-netherite-compat)**: Adds compatibility between Expanded Combat and Advanced Netherite.  
- **[EC Apotheosis Plugin](https://www.curseforge.com/minecraft/mc-mods/ec-apotheosis-compat)**: Adds compatibility between Expanded Combat and Apotheosis.  
- **[EC Aquaculture Plugin](https://www.curseforge.com/minecraft/mc-mods/ec-aquaculture-compat)**: Adds compatibility between Expanded Combat and Aquaculture 2.  
- **[EC Create Plugin](https://www.curseforge.com/minecraft/mc-mods/ec-create-compat)**: Adds compatibility between Expanded Combat and Create.  
- **[EC Cataclysm Plugin](https://www.curseforge.com/minecraft/mc-mods/ec-l-enders-cataclysm-compat)**: Adds Expanded Combat compatibility support for L_Ender’s Cataclysm.  
- **[Create Escalated](https://www.curseforge.com/minecraft/mc-mods/create-escalated)**: Adds tools and components for expanded vertical building in Create contraptions.  
- **[Create Extra Gauges](https://www.curseforge.com/minecraft/mc-mods/create-extra-gauges)**: Expands Create factory gauges with additional measurement and monitoring options.   
- **[Player Animation Lib](https://www.curseforge.com/minecraft/mc-mods/player-animation-library)**: Provides a shared animation library that prevents conflicts between player animation mods.  
- **[Refined Polymorphism](https://www.curseforge.com/minecraft/mc-mods/refined-polymorphism)**: Adds Polymorph recipe selection support for Refined Storage crafting.  
- **[Refined Storage](https://www.curseforge.com/minecraft/mc-mods/refined-storage)**: Adds a scalable network-based storage system for items and fluids with integrated autocrafting.  
- **[Refined Storage Addons](https://www.curseforge.com/minecraft/mc-mods/refined-storage-addons)**: Expands Refined Storage with additional utilities and functionality.  
- **[RS Infinity Booster](https://www.curseforge.com/minecraft/mc-mods/rsinfinitybooster)**: Adds infinite range and dimensional range cards for Refined Storage.  
- **[Deeper and Darker: Resonant Synthesis](https://www.curseforge.com/minecraft/mc-mods/deeper-and-darker-resonant-synthesis)**: Adds resonance-themed items and mechanics as an addon for Deeper and Darker.  
- **[RS Insert Export Upgrade](https://www.curseforge.com/minecraft/mc-mods/rs-insert-export-upgrade)**: Adds a combined insert and export upgrade for Refined Storage.  
- **[Sawmill](https://www.curseforge.com/minecraft/mc-mods/sawmill)**: Adds a sawmill crafting station for expanded wood processing and crafting options.  
- **[Serene & Slice Compat](https://www.curseforge.com/minecraft/mc-mods/serene-slice-compat)**: Fixes irrigation behavior and restores sprinkler sound functionality.  
- **[Structurify](https://www.curseforge.com/minecraft/mc-mods/structurify)**: Simplifies structure configuration and reduces the need for multiple datapacks.  
- **[Tom's Simple Storage](https://www.curseforge.com/minecraft/mc-mods/toms-storage)**: Adds a simple, vanilla-style storage network with easy connectivity.  
- **[Create Trading Floor](https://www.curseforge.com/minecraft/mc-mods/create-trading-floor)**: Adds Create-based systems for automating villager trading workflows.  
- **[Unchipped](https://www.curseforge.com/minecraft/mc-mods/unchipped)**: Allows Chipped blocks to be converted back to their base variants via stonecutter.  
- **[Universal Grid](https://www.curseforge.com/minecraft/mc-mods/universal-grid)**: Adds a universal grid interface for managing Refined Storage networks.  
- **[Create Factory Logistics](https://www.curseforge.com/minecraft/mc-mods/create-factory-logistics)**: Adds jar-based fluid transportation mechanics for Create logistics networks.  
- **[Refined Storage: Requestify](https://www.curseforge.com/minecraft/mc-mods/rs-requestify)**: Automatically keeps Refined Storage networks stocked with specified craftable items.
- **[Corpse x Cosmetic Armor Reworked Compat](https://www.curseforge.com/minecraft/mc-mods/corpse-x-cosmetic-armor-reworked-compat)**: Enables direct equipping of Cosmetic Armor items into their corresponding armor slots from the corpse mod.  
- **[FTB Chunks x Xaero's Compat](https://www.curseforge.com/minecraft/mc-mods/ftbxaerocompat)**: Provides integration and compatibility between FTB Chunks and Xaero’s map mods.
- **[LUMINOUS TAG](https://www.curseforge.com/minecraft/mc-mods/luminous-tag)**: Adds the Decorative Tag item used within LUMINOUS: Nether content.  
- **[LUMINOUS: NETHER](https://www.curseforge.com/minecraft/mc-mods/luminous-nether)**: Expands the Nether with new biomes, hostile mobs, blocks, and decorative elements.  
- **[Endelurgy](https://www.curseforge.com/minecraft/mc-mods/endelurgy)**: A vanilla-friendly mod that introduces new ores, resources, and progression mechanics to the End dimension.

## **Mod Removals**
- **AE2 and Addons**: Replaced with Refined Storage and addons to simplify digital storage and autocrafting progression.  
- **Botany Pots and Addons**: Removed due to misalignment with the pack’s Create-focused direction.  
- **Dungeon Crawl**: Removed due to misalignment with the pack’s Create-focused aesthetic.  
- **Powah**: Removed to keep the pack’s automation identity centered on Create.  
- **Structory and Structory Towers**: Removed due to low loot value and limited thematic consistency.  
- **All The Trims**: Removed as a non-essential feature that introduced bugs and increased load times.  
- **Aquaculture Delight**: Removed to reduce redundancy within Farmer’s Delight addon content.  
- **Casualness Delight**: Removed to streamline Farmer’s Delight addon overlap.
- **Caged Mobs**: Removed due to misalignment with the pack’s Create-focused direction.   
- **Create Mobile Packages**: Removed due to major performance issues in recent versions and replaced with Tom’s Simple Storage integration.  
- **Create Ender Link**: Removed and replaced with Create Utilities to consolidate ender-style functionality.
- **Ender Chests and Tanks**: Replaced with Create Utilities to keep cross-dimensional storage aligned with Create.  
- **Farmers Respite**: Removed to reduce Farmer’s Delight addon redundancy.  
- **Hyper Box**: Removed due to redundancy with Compact Machines.  
- **Item Collectors**: Removed due to aesthetic misalignment and replaced with Create Fishery Industry where applicable.  
- **Personality**: Removed and replaced with ParCool for movement-focused gameplay improvements.  
- **Quark Delight**: Removed to streamline Farmer’s Delight addon overlap.  
- **Repurposed Structures**: Replaced with Create-focused structure generation mods for better thematic consistency.  
- **Create Sounds of Steam**: Removed as a non-essential cosmetic feature.  
- **Mod Grinding Utils**: Removed due to misalignment with the pack’s Create-focused direction.  
- **Miners Delight**: Removed to simplify Farmer’s Delight addon overlap.
- **Chargers**: Removed and replaced with Flux Networks
- **Enlightened End**: Removed due to misalignment with the pack’s Create-focused direction.
- **Apotheotic Additions**: Removed due to being an outdated and incomplete mod that introduced multiple bugs and stability issues.
