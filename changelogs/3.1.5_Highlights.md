# **Modpack Patch Notes: Version 3.1.5**
**Release Date:** September 23rd, 2026

### *The Final Frontier*

## **Overview**

Version **3.1.5** is a maintenance, performance, and stability update focused on refining the technical foundation of *Create - Forge Frontier* following continued testing of the Version **3.1.x** release cycle.

This release streamlines the modpack's optimization stack by removing components that were no longer necessary or providing meaningful performance improvements, while introducing new performance and utility mods to better support long-term stability. Create Power Loader has also been replaced with Chunk Loaders, accompanied by new Create-based crafting progression and custom KubeJS integration.

Additional improvements include updated Dirty Dust processing, refined mob spawning configurations, interface adjustments, ServerCore performance tuning, and a broad collection of mod updates.

These changes are designed to improve stability, compatibility, and server performance without introducing major changes to the progression or world generation established throughout *The Final Frontier*.

---

## **Key Highlights**

- **Optimization Stack Cleanup** - Removed numerous redundant, unused, or ineffective optimization and utility mods following continued performance testing.

- **New Performance and Utility Mods** - Added C2ME Forge and several targeted client and server improvements to strengthen the modpack's technical foundation.

- **Chunk Loader Overhaul** - Replaced Create Power Loader with Chunk Loaders, providing more manageable chunk-loading behavior and automatic inactivity handling.

- **New Create-Based Chunk Loader Progression** - Added custom Mechanical Crafting and Sequenced Assembly recipes, incomplete items, and assets for the new Chunk Loader progression.

- **KubeJS Recipe Improvements** - Updated Dirty Dust byproducts for Calorite, Ostrum, Stellaris, and Uraniumnite alongside new recipe and registry changes.

- **Mob Spawning Adjustments** - Disabled natural spawning for Murmurs, Cave Centipedes, and Glares to provide greater control over mob populations.

- **Server Performance Tuning** - Reduced ServerCore maximum distance settings to further improve overall server performance.

- **Compatibility and Interface Improvements** - Adjusted Dark Mode Everywhere's inventory button placement and updated numerous mods to newer versions for improved compatibility and stability.
