## ❌ Mod Removals
- CapeJS: I don't have the time/energy to create custom capes for this pack
- Custom Credits: Not Needed since Quests cover everything essential
- Fireproof Boats: Boats burn up in lava, so it doesn't function like intended
- Model Gap Fix: Not Essential, causes some buggy rendering
- Sound Phyics Remastered: Causes FPS issues with Create Factory setups, not ideal for this pack
- Toast Control: Not Essential
- Clickable Advancements: Doesn't work like its supposed to
- Canary: Replaced with Radium Reforged
- Iris/Flywheel: Replaced with Colorwheel and Colorwheel Patcher
