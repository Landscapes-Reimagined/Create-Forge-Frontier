# 🛠️ **Create - Forge Frontier: Version 2.4.2 Update**  
### *Hotfix Patch – Performance Tweaks*

This patch delivers critical **performance optimizations**, **mod cleanups**, and **compatibility enhancements** to improve gameplay stability, particularly for players building large-scale Create contraptions. Redundant and underperforming mods have been removed, while targeted additions focus on boosting frame rates, reducing simulation lag, and improving the overall experience.

> ⚠️ **Reminder:** As with any update, we strongly recommend **backing up your world** before installing the patch.

---

## ❌ Mod Removals
- **CapeJS**: Custom cape support is not a development priority at this time  
- **Custom Credits**: Quest content now fully replaces the need for external credit screens  
- **Fireproof Boats**: Does not function as intended; boats still burn in lava  
- **Model Gap Fix**: Minimal benefit; causes visual glitches in some cases  
- **Sound Physics Remastered**: Significant FPS impact during Create factory operation  
- **Toast Control**: Nonessential; UI streamlining handled by other systems  
- **Clickable Advancements**: Inconsistent functionality within our quest system  
- **Canary**: Functionally replaced with **Radium Reforged** for improved performance  
- **Iris/Flywheel**: Replaced with **Colorwheel** and **Colorwheel Patcher** for better rendering support  

---

## ✅ Mod Additions

- **[BadOptimizations](https://www.curseforge.com/minecraft/mc-mods/badoptimizations)**  
  Removes inefficient vanilla behavior and reduces pathfinding complexity to improve overall server and client performance.  

- **[Neruina](https://www.curseforge.com/minecraft/mc-mods/neruina)**  
  Optimizes internal game mechanics such as ticking, memory usage, and task scheduling for smoother gameplay.  

- **[DespawnTweaker](https://www.curseforge.com/minecraft/mc-mods/despawntweaker)**  
  Provides greater control over item despawn mechanics, helping to prevent lag from item buildup.  

- **[Despawn Tweaks](https://www.curseforge.com/minecraft/mc-mods/despawn-tweaks)**  
  Introduces smarter entity and item despawning behavior to reduce entity overload.  

- **[Dynamic FPS](https://www.curseforge.com/minecraft/mc-mods/dynamic-fps)**  
  Conserves system resources by reducing framerate when the game window is inactive or minimized.  

- **[Mobtimizations - Entity Performance Fixes](https://www.curseforge.com/minecraft/mc-mods/mobtimizations)**  
  Improves entity performance by optimizing AI, bounding boxes, and update frequency.  

- **[Radium Reforged](https://www.curseforge.com/minecraft/mc-mods/radium-reforged)**  
  A performance enhancement mod based on Lithium, refining block updates and server-side logic.  

- **[TxniLib](https://www.curseforge.com/minecraft/mc-mods/txnilib)**  
  A required support library for performance-oriented mods like Mobtimizations and Neruina.  

- **[Colorwheel](https://www.curseforge.com/minecraft/mc-mods/colorwheel)**  
  A lightweight and modern rendering library that replaces Flywheel to enhance rendering performance.  

- **[Colorwheel Patcher](https://www.curseforge.com/minecraft/mc-mods/colorwheel-patcher)**  
  Ensures mod compatibility and rendering stability for Colorwheel-based environments.  

- **[Observable](https://www.curseforge.com/minecraft/mc-mods/observable)**  
  Adds diagnostic and data visibility hooks to support performance and optimization mods.  

---

## 🔥 **Why These Changes?**

This update was developed with one goal in mind: **optimize Forge Frontier for smoother, more reliable gameplay**. Mods that introduced performance issues, offered marginal value, or caused compatibility concerns have been removed. In their place, we’ve introduced **specialized performance tools** to support low-latency play in factory-intensive environments.

These changes are especially beneficial for players on mid-range systems, those running automated setups, or anyone experiencing lag during heavy world interaction. The new additions were carefully selected for **lightweight, targeted performance gains** without sacrificing modpack depth.
